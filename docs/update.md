# 自动更新

InkStream 内置应用内自动更新。启动时会在后台检查新版本，有更新时弹一个不打扰的提示，点一下下载、重启就升级好了，不用再自己去下载页。

当前发行版本配置为 [2.1.0](https://github.com/KRPCT/InkStream/releases/tag/v2.1.0)；安装包与更新清单的就绪状态以发行页为准。发布成功表示对应发布流水线完成，实际安装、升级和平台交互仍按各自验收记录确认。

## 怎么用

- **自动检查**：每次启动后台静默检查最新版本。有更新时弹出对话框「InkStream X 现已可用」，可选「现在更新」或「稍后」；无更新或离线时不打扰。
- **手动检查**：标题栏 **帮助 → 检查更新**，或命令面板（`Ctrl+Shift+P`）执行「帮助：检查更新」，或 **帮助 → 关于 InkStream → 检查更新**。无更新会提示「已是最新版本」，检查失败（如断网）会明确提示而非误报最新。
- **下载与安装**：点「现在更新」后显示下载进度条；完成后点「重启并安装」即应用新版本（也可稍后手动重启生效）。下载过程中对话框不可关闭，避免中断。

## 安全

- 每个更新包都经过开发者私钥签名，InkStream 用内置公钥验签通过后才安装，下载途中被篡改的包会被拒绝。私钥只存在于发布流水线，不会随应用分发。
- 更新清单（latest.json）与安装包都从项目 [GitHub Releases](https://github.com/KRPCT/InkStream/releases) 获取，走 HTTPS。
- 检查与下载由应用原生层（Rust）完成，不经网页层，不受网页安全策略影响。

## 注意

- 自动更新面向正式安装版；启动仍会调用检查入口，开发／未打包环境或网络失败时静默处理。手动检查失败会给出提示，不能写成开发版完全不调用更新器。
- 从 **v1.1.2 起**的安装版才内置更新器；更早版本需手动下载一次新版，此后即可自动更新。
- macOS / Windows 安装包未做系统代码签名，首次安装可能有「未知开发者」提示，属正常。

## 发布与更新清单

标签 `v*` 触发的发布先建立草稿，构建 Windows x64、Linux x64、macOS Apple Silicon 安装包及更新载荷，校验各平台更新签名条目并生成 `latest.json` 后才公开。手动触发 Release 工作流只提供构建产物下载，不创建公开版本。更新载荷签名与 Windows Authenticode／macOS 公证是不同步骤，不能互相替代。

CI 的类型检查、前端测试、Rust 全目标测试与 Release 打包各有执行范围；BDD 人工映射、物理 IME、真实账户和跨平台视觉／性能的剩余工作见[自动化绑定与验收边界](./specs/AUTOMATION.md)。
