# 阅读模式

InkStream 可阅读 txt、Markdown、Word（docx）、EPUB 电子书和 PDF。阅读视图覆盖工作区中的编辑器与两侧面板，保留正文和阅读工具栏，不切换操作系统全屏。

## 支持的格式

- **txt**：纯文本
- **md / markdown**：Markdown 文档的阅读视图
- **docx**：Word 文档（转换为排版后的正文）
- **epub**：电子书（按章节顺序连续呈现）
- **pdf**：逐页渲染、滚动阅读

## 怎么进入

- **docx / epub / pdf**：直接打开即自动进入阅读模式（它们不可编辑）。打开方式包括：文件菜单 → 打开文件、把文件拖进窗口、或在系统里用 InkStream「打开方式」。
- **txt / md / markdown**：默认在编辑器中打开；通过「视图 → 阅读模式」或命令面板（`Ctrl+Shift+P`）→「视图：阅读模式」进入阅读。阅读视图读取磁盘文件，未保存的正文请先保存；未命名草稿需先另存为文件。

## 工具栏

阅读界面顶部的工具栏只有几个按钮：

- **文体切换**（小说 / 文献）：见下节。
- **排版设置**：文本阅读可调整字体、字号、版心宽度与页边距；PDF 不显示这些文本重排控件。
- **配色**：用「亮 / 护眼 / 夜间」分段按钮选择，当前项高亮。
- **目录**：文本提取到标题后显示，点击可定位到对应段落。
- **书签**：文本阅读可添加当前位置、跳转或删除书签；PDF 当前不提供这个块级书签入口。
- **上一章 / 下一章**：从书架打开有章节结构的书籍时显示。
- **加入书架**：启用书架后，对尚未上架的 txt / docx / epub / pdf 显示；Markdown 不加入书架。
- **关闭**：回到编辑器。

## 自动识别小说 vs 文献

打开文档时，InkStream 会根据正文特征判断它更像**小说**还是**文献 / 论文**，并据此切换排版：

- **小说**：衬线字体、较宽的行距、段首缩进、两端对齐，接近纸质书的观感。
- **文献**：无缩进、紧凑行距、较窄的版心，接近论文 / 报告的观感。

判断依据是章回标记（如「第一章」「Chapter 1」）、对白密度、摘要 / 参考文献等线索。判断不准时，点工具栏的文体按钮手动在「小说 / 文献」间切换即可。

## 沉浸与退出

进入阅读模式后，编辑器、侧边栏、右侧面板都被盖住，状态栏折叠成「阅读模式 · 文件名」。底层编辑器没有卸载，关闭阅读后回到原编辑状态。书架已启用且当前文件尚未上架时，关闭前会提示是否加入，可选「暂不」。

## 书架与续读

在「设置 → 通用」启用书架后，标题栏出现「书架」菜单，可导入书籍文件或文件夹。文件夹支持「书 → 卷 → 章」结构，书卡显示进度，点击可续读。移除书卡只移除书架记录，不删除原文件。

文本按正文块记录位置，PDF 按页记录；启用书架持久化后，书籍记录、进度与文本书签保存在本机，关闭书架开关不清除已有数据。阅读配色和排版偏好是本次应用会话状态。

单文件读取上限为 100MiB。原生读取使用分块传输，随后仍需在内存解析；PDF 按视口逐页绘制。文件大小上限不代表全部格式和设备已通过相同的性能验收。
