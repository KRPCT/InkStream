# DDD 工作台演进计划

2026-09-13。2.0.0 的文档会话、项目会话、索引与 Git 修复已合并。本计划描述其后的多栏工作，不把已实现项目档案重新列为未来实体。

## 职责与边界

术语唯一来源为 [CONTEXT](../CONTEXT.md)，代码职责见 [ARCHITECTURE](ARCHITECTURE.md)。主编辑器拥有正文，项目协调器拥有切换与恢复，工作台只管理目的地和布局，文献浏览管理只读库快照与资料选择。正文和项目身份不复制到页面私有模型中。

## 纵向切片

| 切片 | 用户结果 | 复用边界 |
| --- | --- | --- |
| 项目轨与导航 | 快速选择真实项目，失败保留文稿并可理解原因 | 项目 actions/session，工作台状态 |
| 概览/文稿/版本 | 查看真实项目资料与 Git 历史，再返回原文稿 | 现有文档与 Git stores/flows |
| 文献详情 | 选中只浏览，明确插入才改当前文稿 | Zotero 库身份与已有引用编辑入口 |
| 布局与键盘 | 栏宽、折叠、Tab/方向键和窄视口保持可用 | 现有布局恢复/写回及能力降级 |

每个切片用 Given/When/Then 说明可观察行为，先证明失败，再完成实现。规格与自动检查逐项映射，ComputerUse 是独立用户层验收。未绑定或未执行的场景不能被其它测试通过覆盖。

## 约束

主 EditorView 常驻；视图切换不释放正文或清 dirty。项目切换继续先保存与快照，失败停留。库切换使过期查询和选择失效。缩放不覆盖保存的栏宽。保持当前文件格式与元数据版本，本轮不引入通用 DDD 框架或新的正文数据库。

实施与完成状态统一见 [EXECUTION-PROGRESS](EXECUTION-PROGRESS.md)。原 2026-09-11 计划保存在本地审计源，不作为当前待实施清单。
