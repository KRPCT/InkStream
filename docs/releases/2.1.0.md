# InkStream 2.1.0

InkStream 2.1.0 完善了多栏写作工作台与文献浏览体验。

- 概览、文稿、文献、版本四个工作区入口，视图切换保留当前文稿、选区与撤销记录。
- 多项目快捷轨、真实项目概览与版本时间线，项目切换失败后保留原文稿并显示原因。
- 文献先选择看详情，再明确插入；插入可单独撤销，长详情的操作按钮保持可见。
- 工作区、文稿及工具标签支持方向键与 Home/End；两侧折叠独立，缩放保留用户栏宽。
- 统一纸白、石墨灰、低饱和灰绿与宋体风格正文，优化暗色标记、滚动条和工具密度。
- 修复模式菜单被裁剪、退出简易模式后创作工具空白等问题。软件内更新公告已同步。

提供 Windows x64、macOS Apple Silicon、Linux x64 安装包，包含应用内自动更新清单与载荷签名。

验证：多栏实现已通过三平台 CI、1910 项前端断言、41 项显式行为绑定和三轮 Windows ComputerUse。文献用户流程使用受控本机 HTTP 数据；真实账号、物理 IME、安装图标及完整平台体验矩阵仍按专项 issues 管理。更新载荷签名与操作系统发行者代码签名是不同环节。
