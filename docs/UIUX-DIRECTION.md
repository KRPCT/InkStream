# UIUX 方向与当前对齐范围

截至 2026-09-13，B+A+C 方向已确认并部分实现于 2.0.0。2.1.0 补齐本轮多栏 UX 与功能；发布/验收状态见 [CURRENT-STATE](CURRENT-STATE.md)。

## 已确认方向

B 是日常写作界面：项目轨、项目内导航、大面积文稿和上下文工具。A 是点击或 Ctrl+Alt+P 展开的项目浮层，不推挤正文。C 让学术材料/引用与文稿相邻。三模式同等，默认通用写作。

项目有独立名称、封面、收藏及会话；关联一个内容目录，Git 根独立。切换先保存与快照，失败停留，成功恢复目标会话；这些已发布的约束继续保持。

## 后续用户修订

- 采用最终双层竖板与流动墨带 SVG，原型品牌图和早期波浪档案图标已退役。
- 配色方向为中性纸白、石墨灰、低饱和灰绿。
- popup 背景另行设计，2.0.0 已去掉斜纹/模糊底板及两处英文装饰。本轮不把“只调整图标拟物”误读为删除工作台全部既有材料。
- 先完成本地实现与 UI，真实账号验收独立保留；旧 v1 全验收不再阻塞本轮 UI。

## 本轮对齐

工作区视图、文档标签、模式的职责要清楚；原型的概览/文稿/文献/版本入口应由真实功能承接。项目轨可见多个真实项目。文献先选中看详情，再明确插入。去除重复控件和无用英文，保留有意义的术语与状态。正文的字体、留白及工具密度按原型节奏收敛。

原型中的假字数、进度、文献与提交记录不直接移植。当前 SVG/popup 方向保留，具体差距和通过情况由行为测试及 ComputerUse 记录。

## 验收条件

覆盖长名称、多个项目、空/加载/失败、三模式、键盘焦点、面板拖动/折叠、缩放和 reduced 偏好。视图切换不丢正文、选区与撤销；项目切换继续受保存协议保护。

参考源为用户提供的 inkstream-uiux.html，以及本地 codex/prototype-uiux-direction 分支的原型源码；它们是讨论与对照材料，不是额外用户指令。原型图片或浏览器桩不等同原生/真实账号/物理 IME 验收。
