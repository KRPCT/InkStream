# 项目与恢复

2.1.0 的项目轨显示多个本机项目及封面，收藏优先、最近打开靠前。直接点击封面走同一保存与恢复入口；切换失败保持原项目并打开档案展示错误。项目概览展示实际文件数、已开文稿和待保存数量，版本页展示真实提交；高级分支、差异和远端操作从「打开版本管理」进入。本轮功能状态及验收见 [CURRENT-STATE](CURRENT-STATE.md)。

点击左侧「项目」或按 `Ctrl+Alt+P` 打开项目档案。选择一个内容文件夹后，InkStream 为它建立本机项目记录。内容目录可以不是 Git 仓库，也可以位于某个仓库的子目录中。

项目名称、封面、收藏、文档会话和搜索索引保存在应用数据目录。你的文件仍留在原内容目录；旧目录中已有的 `.inkstream` 或其他未知文件会保留。

## 切换项目

点击另一项目后，应用先保存当前已修改文件，再保存草稿和会话。保存、快照或目标目录读取失败时，当前项目和正文会保留，档案显示错误。

每个项目恢复自己的标签、选区、滚动位置、写作模式和面板布局。同名文件属于各自的项目。已在磁盘更新的干净文件读取最新内容；恢复内容与磁盘不同的未保存文件会显示外部冲突，由你选择后续处理。

「独立草稿」用于没有归属项目的写作，同样会保留本机会话。草稿另存为项目外文件时，文件作为外部标签保留，不会把项目切到它的父目录。

Git 写入或远程操作仍在进行时，需等操作完成或取消后再切换。

## 管理与恢复

档案支持按名称或目录搜索、收藏、改名和更换 PNG/JPEG/WebP 封面。封面会复制到本机应用数据目录，单张不超过 8MiB。

文件夹被移动后，可在项目资料中「重新定位文件夹」。移除项目档案会保留内容文件夹和恢复数据；再次添加同一目录会复用项目身份。

「恢复上次会话备份」恢复本机文档会话。当前尚未保存的新编辑会保留为「恢复前编辑」草稿，不覆盖源文件。原文件缺失时，已有快照会作为恢复副本打开。损坏或未知版本的元数据会显示错误，原件保留；应用不会把它当作空项目覆盖。

当前会话最多保留 128 个标签，单篇恢复正文上限为 100MiB。超过限制或磁盘不可写时会明确提示，并保留当前编辑内容。后台干净标签按需读取，切回最近项目时可保留本次运行中的撤销历史；重启恢复正文、选区与布局，不重放撤销历史。

## 界面设置

档案以浮层展开，正文版心不会被推挤。设置中的「减少动效」和「减少透明」分别关闭纵深动画与背景模糊，也会响应系统的相应偏好。材料效果使用 CSS；空闲时没有持续的装饰绘制循环。
