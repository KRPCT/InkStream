# 公式编号与引用

在学术工具栏点击“公式编号”，或执行命令“学术：公式编号”。当前 Markdown 文档会启用公式编号，并为尚无标签的块公式补充唯一标签。再次执行会保留已有标签；这次操作可单步撤销。

编号适用于 `$$…$$`、`math` / `latex` / `typst` 代码围栏以及 `:::typst`。每个块算一个公式，按文档顺序从 1 编号。数字在预览和导出时计算，不写入 LaTeX 或 Typst 源码。插入、删除或移动公式后，编号和不带别名的引用会随顺序更新。

编号状态和标签保存在 Markdown 中，例如：

````markdown
<!-- equation-numbering -->

```latex
E=mc^2
```
<!-- equation:energy -->

见 [[#eq:energy]]。
````

`energy` 是稳定标签；即使公式变为第 3 个，引用仍写 `[[#eq:energy]]`，显示为“式（3）”。Live Preview 中 Ctrl/Cmd+点击引用，或聚焦引用后按 Enter，可跳到当前文档中的公式源码。带 wiki 别名时显示用户指定的别名，目标仍由标签确定。

标签应紧随对应公式，中间只留空白。可使用字母（含中文）、数字、下划线、点和连字符，最长 80 个字符。重复、非法、孤立或未闭合的公式块会阻止批量编号并给出提示。重命名标签时，应同步修改引用；未解析引用会明确显示，不能跳到一个猜测目标。

新插入的公式会参与编号；再次点击“公式编号”可为其生成引用标签。用公式上的删除按钮删除时，关联标签会一起删除。在 Source 模式手动移动公式时，应把紧随其后的标签一起移动。

HTML 导出使用相同的文档序与标签，生成编号和本页引用链接；合法编号及 bibliography 注释不会出现在正文。普通或未知 HTML 仍转义。数学内容沿用现有导出能力：`math` / `$$` 可使用数学渲染器，LaTeX 与 Typst 围栏保留源码，此功能不等同于整篇学术文档编译。

大文档的基础编辑档暂停完整编号扫描和 Live Preview。需要新增编号标签时，先显式启用完整排版；基础档不会因点击编号而自动切换模式或改写文档。显式 HTML 导出仍按导出文档内容计算已有编号。

## 导出 LaTeX 公式 PDF 片段

将光标放入一个 `latex` 代码围栏，点击学术工具栏“公式 PDF”，或执行“学术：导出公式 PDF 片段”。文件菜单的“导出为 → 公式 PDF 片段…”调用同一动作；公式悬浮工具栏也有“导出公式 PDF”按钮。双栏编辑模式下导出的是正在编辑的公式。

片段以 12pt 数学字号和四周 8pt 留白输出，保留公式矢量图形。应用先转换当前公式，再让你选择 `.pdf` 保存位置；保存取消不写文件。编译期间编辑、切换或关闭文档会取消旧公式导出，失败时可重试。基础编辑档需要先显式启用完整排版。

此入口支持 MathJax 的 LaTeX 数学表达式及已加载的 `base`、`ams`、`newcommand` 扩展；它不执行完整 TeX 文档、任意宏包或外部文件。公式错误会给出原因，不能作为成功的 PDF 保存。公式标签和文档编号不改变片段源码。文件菜单原有的“PDF…”仍用于整篇文档的系统打印。
