# 简易模式

如果你只想把 InkStream 当成一个普通的 Markdown 编辑器，写点东西、存成文件，用不上双向链接、知识图谱、Git、Zotero 这些进阶能力，可以打开「简易模式」。它会把界面收窄到基础写作，并且不在你的工作区里创建索引文件夹。

## 它解决什么

全文搜索与双向链接使用本机应用数据目录中的项目索引。只写纯文本时，简易模式可以关闭索引和相关后台工作。无论是否启用简易模式，新索引都不会写到你的内容文件夹。

## 怎么开

设置 → **通用** → **简易模式** 开关。打开即生效，也随时可关。

## 开启后会怎样

**关闭高级功能**，界面只留基础写作：

- 侧边栏：隐藏全文搜索、Git 面板、Zotero 文献库、章节-场景树，只保留文件树。
- 右侧面板：只保留大纲，反链与局部图谱隐藏。
- 状态栏：保留文件路径、光标位置、渲染模式和会话暂存反馈，隐藏 Git 分支、文档字数／目标、引用、模式切换；已处于 Creative 时的写作 HUD 入口仍可用。
- 命令面板 / 菜单 / 快捷键：知识图谱（Ctrl+G）、Git Graph、模式切换、插入引用、切换文档语言等高级命令一并隐藏，即使按对应快捷键也不会触发。

**关闭索引**：简易模式下打开或切换项目不启动索引，反链、未链接提及和图谱工具隐藏。

**保留的基础能力**：纯文本编辑、项目档案与草稿恢复、Live Preview 与 Source 切换、文件树增删改、自动保存、文件导出和阅读模式照常可用。

## 随时可逆

关闭简易模式后，高级功能会恢复，当前项目按索引会话流程重新打开／刷新索引；切换项目时仍按各项目隔离。简易模式不会改动你的正文。书架由自己的设置开关控制，与简易模式独立。

旧工作区已有的 `.inkstream/` 文件夹会保留；应用使用新的本机项目索引，不自动删除旧目录或其中的未知文件。
